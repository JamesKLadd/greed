# Seasonal UI review

Development review for Greed's three seasonal appearances, included in v0.8.5.
The screenshots and sample score cards in this folder are local review fixtures.

| Appearance         | Automatic dates, inclusive | Direction                                          |
| ------------------ | -------------------------- | -------------------------------------------------- |
| The Haunted Parlor | October 1–31               | Plum felt, lantern light, brass, cobwebs and bats  |
| The Fireside Lodge | December 1–January 5       | Evergreen velvet, walnut, pine and warm lights     |
| The Boardwalk Club | June 1–August 31           | Ocean teal, sunset coral, teak and seaside details |

Automatic dates follow America/Chicago, as the challenge calendar does. The
standard appearance fills the gaps. Settings also offers Classic or any seasonal
appearance year-round. Seasonal choices remain separate from the Classic
presentation fallback.

## Browser checks

- All five appearance choices apply immediately, save, and survive reload.
- Fourteen instants immediately before and at Chicago season boundaries include
  the Christmas year transition and January 6 return to Classic.
- An active practice game keeps Halloween across October 31 midnight, then
  returns to Classic on Home. Menus refresh the automatic theme without reload.
- Actual guest Daily and Weekly entry screens continue updating across midnight.
  A mounted Weekly `ChallengeRun` stays pinned; restarting the isolated weekly
  fixture mounts the next run with the new season.
- A real two-seat local game completed in two throws without recording results.
  Its result retained Halloween across midnight; Play again renewed the table
  to Classic.
- At 320 pixels, English Halloween, Spanish Christmas and French Summer settings
  and practice screens retain large text, high contrast and reduced motion
  without horizontal overflow.
- A Classic presentation fallback still loads with a manual seasonal choice.
- Equipped Crimson dice and Midnight Blue table retain their material colors
  across all seasons. Review uses an isolated synthetic local profile.
- [Eight seats](halloween-eight-seat-320.png) and a separate
  [six-seat team table](halloween-six-seat-teams-320.png) fit 320 pixels with
  large text and high contrast. Goal indicators, dice and controls remain visible.
  Team play supports four or six seats.
- [Online table preview](christmas-online-phone.png) uses the production shared
  table view with isolated core state, not a real server connection. Clock,
  reconnecting and spectator states were checked. Actual online transport was
  covered by the existing automated suite.
- Seasonal win ornaments appear in Home’s presentation-only celebration demo:
  [Halloween](halloween-win-flourish-phone.png),
  [Christmas](christmas-win-flourish-phone.png), and
  [Summer](summer-win-flourish-phone.png). Only the chosen season is visible;
  reduced motion disables its animation. The ornaments do not intercept input.
- Results dialogs and in-game menus follow the selected palette. The
  [Halloween menu](halloween-menu-phone.png) and its
  [high-contrast variant](halloween-menu-high-contrast-phone.png) were checked
  for readable surfaces and Escape dismissal.
- Storage denied by the browser still permits a live seasonal choice and another
  settings change. An unknown saved theme falls back to Automatic.
- Screenshots and score images were inspected for text and decoration overlap.

The browser contexts disable usage measurement and audio, block external HTTP
requests and WebSockets, and touch no production database or account.

## Automated verification

Full typecheck, lint, formatting and production build passed. The full test run passed
958 tests with 59 skipped database-gated or legacy checks. An initial run under
the restricted network sandbox could not bind the tests’ localhost HTTP and
WebSocket listeners; the run with local network access passed. No production
service or database was used for these tests.

The v0.8.5 production build was also checked in Chromium at 390 × 844: Home
shows v0.8.5, Automatic selects Halloween on the current Chicago date, and the
[in-game update log](v0.8.5-update-log-phone.png) opens on v0.8.5 with the exact
single release note supplied by the developer and the October 15 release date.

## Reproduce

Start the client with:

```sh
npm --workspace @greed/client run dev -- --host 127.0.0.1
```

Choose a theme in Settings, then open these local routes:

- `/` — real home screen.
- `/?table-play&players=4&goal=3000&seed=2525` — deterministic playable local table.
- `/?practice=1` — real unranked practice challenge.
- `/?support-review&screen=settings` — real settings view with development review
  controls; this route saves settings to this browser.
- `/?classic=1` — Classic presentation recovery.
